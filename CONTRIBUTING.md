# Contributing

Open focused issues and pull requests with synthetic reproductions. Keep credentials, personal infrastructure details and private logs out of source, tests, images and commit messages. All screenshots must come from demo mode.

Use Python's standard library for runtime code. Tests must not require an account, network, clipboard access, system package installation or a running VPN. Follow the existing theme roles rather than adding fixed palette colors to production QML. New API shapes need fixture-based compatibility tests.

Do not commit local configuration or edit production settings for a test. Describe how changes behave offline and with restricted resource access. See docs/releases.md before preparing a release.
